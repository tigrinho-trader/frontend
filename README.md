# frontend

Parte do projeto **Tigrinho Trader** (disciplina Projeto de Software).

## Finalidade

Interface "tigrinho": tela de login (Auth0), tela de rodada/aposta e extrato de saldo. Fala exclusivamente com o `api-gateway` via REST, autenticado com o token OAuth2 do Auth0. Nao conhece os servicos internos.
